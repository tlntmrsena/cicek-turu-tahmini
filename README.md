# Çiçek Türü Tahmini | Makine Öğrenmesi

## Proje Hakkında
Bu proje, Python ve makine öğrenmesi yöntemleri kullanılarak çiçeklerin özelliklerinden yola çıkılarak türlerinin tahmin edilmesi amacıyla geliştirilmiştir.

## Projenin Amacı
Çiçeklere ait ölçüm verilerini analiz ederek uygun bir makine öğrenmesi modeliyle çiçek türlerini sınıflandırmak.

## Kullanılan Teknolojiler
- Python
- Google Colab
- Makine Öğrenmesi

## Proje Aşamaları
1. Veri setinin incelenmesi
2. Veri ön işleme ve analiz
3. Makine öğrenmesi modelinin oluşturulması
4. Modelin eğitilmesi ve test edilmesi
5. Tahmin sonuçlarının değerlendirilmesi

## Proje Dosyası
Projenin Python kodları ve analizleri GitHub deposundaki Jupyter Notebook (.ipynb) dosyasında bulunmaktadır.

## Geliştirme Ortamı
Google Colab
